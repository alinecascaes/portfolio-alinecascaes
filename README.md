# Portfólio Aline Cascaes

Aplicação de portfólio pessoal desenvolvida com React e TypeScript, apresentando experiência, projetos e stacks técnicas em uma página única, com tema claro/escuro e formulário de contato funcional.

## Funcionalidades

- Seções: Sobre, Experiência, Projetos, Stacks e Contato
- Tema claro e escuro com persistência
- Menu mobile com destaque da seção ativa
- Timeline de experiências
- Modal de detalhes dos projetos com links de deploy e repositório
- Formulário de contato com validação e envio via EmailJS
- Layout responsivo

## Decisões Técnicas

- **Tailwind CSS v4** com design tokens no `@theme` e troca de tema via CSS variables
- **React Hook Form + Zod** para validação tipada do formulário
- **EmailJS** para envio de mensagens sem backend

## Tecnologias

- React
- TypeScript
- Tailwind CSS
- React Hook Form
- Zod
- EmailJS
